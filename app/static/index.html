CLI Zero-RAM Streaming

Upload directly from your terminal using curl -T. QR-Drop will respond with a full ASCII box summary and a scannable terminal ASCII QR code.

Windows PowerShell & Command Prompt 
curl.exe -T report.pdf http://localhost:8000/report.pdf
Linux / macOS Terminal 
curl -T archive.tar.gz http://localhost:8000/archive.tar.gz
Burner Mode: 1 Download • 10 Minutes 
curl.exe -H "X-Max-Downloads: 1" -H "X-Expiry-Minutes: 10" -T secret.env http://localhost:8000/secret.env
Download via CLI (HTTP Range Supported) 
curl -C - -OJ http://localhost:8000/d/<PIN>
